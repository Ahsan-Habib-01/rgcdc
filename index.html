Admin Portal • Module 2 (Graph Theory Allocation)

Power-Pairing & Hungarian Algorithm Cost Matrix

Solves Minimum Weight Perfect Matching in O(V³) over Bipartite Graph G = (Judges ∪ Rooms, E)

1. Strict Power-Pairing

Teams are sorted by (Points DESC, Speaks DESC) and paired strictly within point brackets. Side balance (GOV/OPP or OG/OO/CG/CO) is optimized per bracket.

2. Hard Constraints (Cost = ∞)

If Judge i shares an institution with any team in Room j OR has judged any team in Room j in a previous round, C[i, j] = 10⁹ (FORBIDDEN).

3. Kuhn-Munkres Cost Function

Feasible edges evaluate C[i,j] = 3.5·W_room·(10.5 - S_judge) + 0.8·(W_room - S_judge)², guaranteeing high-bracket rooms get the highest-rated conflict-free chairs.
